在线官方摄影评比 / 大赛（看顶级作品的入口）

定期翻这些奖的获奖作品库——是世界范围内被筛选出来的好照片合集，比刷小红书涨眼力快得多。看的时候顺手记下：构图、光线、瞬间、叙事——为什么它能拿奖。

  • 哈苏大师赛 Hasselblad Masters — hasselblad.com/masters，每两年一届，分11个类别，画质与人文兼具
  • 索尼世界摄影大赛 Sony World Photography Awards — worldphoto.org，体量最大，专业组+公开组+学生组,题材最广
  • 世界新闻摄影比赛(荷赛)World Press Photo — worldpressphoto.org，新闻纪实顶级
  • 国家地理摄影大赛 National Geographic Photo Contest — 自然 / 人文 / 旅行类标杆
  • IPA International Photography Awards — photoawards.com，综合性大赛，分类细
  • LensCulture Awards — lensculture.com，多届主题赛(肖像、街拍、新视野)，作品偏当代艺术口味
  • Nikon Photo Contest — nikon-photocontest.com，亚洲视角占比高
  • Magnum Photos — magnumphotos.com，不是比赛，是顶级图片社的作品库，纪实摄影圣地
  • 荷赛中国 / 华赛 — 中国国际新闻摄影比赛，国内视角

经典导演（进修片单的骨架）

按地区分组列出。审美派、思想派、形式派都包含。看的时候建议按导演成体系刷——一次盯一个人，看完三五部再换下一个，比东一榔头西一棒子有效得多。

日本

  • 黑泽明 — 七武士 / 罗生门 / 影武者（叙事+视觉双高峰，人性母题）
  • 小津安二郎 — 东京物语 / 秋刀鱼之味（榻榻米机位，家庭剧静默美学）
  • 是枝裕和 — 步履不停 / 小偷家族 / 海街日记（继承小津的当代衣钵）
  • 今敏 — 红辣椒 / 千年女优 / 未麻的部屋（结构与意识流大师）
  • 北野武 — 花火 / 菊次郎的夏天（暴力与温情并存的极简风格）
  • 岩井俊二 — 情书 / 燕尾蝶（青春+光影美学）

欧洲

  • 塔可夫斯基（Tarkovsky） — 镜子 / 潜行者 / 乡愁（电影即诗，时间的雕刻）
  • 伯格曼（Bergman） — 第七封印 / 野草莓 / 假面（宗教与存在主义）
  • 库布里克（Kubrick） — 2001太空漫游 / 闪灵 / 发条橙 / 巴里林登（控制狂的视觉美学）
  • 费里尼（Fellini） — 八部半 / 甜蜜的生活（意大利新现实主义→超现实）
  • 安东尼奥尼（Antonioni） — 奇遇 / 放大 / 红色沙漠（现代性的疏离感）
  • 罗伊·安德森（Roy Andersson） — 二楼传来的歌声 / 寒枝雀静（每帧都是油画的构图天才）
  • 戈达尔（Godard） — 精疲力尽 / 狂人皮埃罗（法国新浪潮）

美国

  • 韦斯·安德森（Wes Anderson） — 布达佩斯大饭店 / 法兰西特派（强迫症对称+饱和色美学）
  • 大卫·林奇 — 穆赫兰道 / 蓝丝绒（梦境式叙事，潜意识影像）
  • 保罗·托马斯·安德森（PTA） — 血色将至 / 大师 / 魅影缝匠
  • 泰伦斯·马力克（Terrence Malick） — 生命之树 / 细细的红线（自然+哲学+诗）
  • 大卫·芬奇 — 搏击俱乐部 / 社交网络 / 七宗罪（你看过搏击俱乐部了）
  • 科恩兄弟 — 老无所依 / 缺席的人 / 醉乡民谣（黑色幽默+宿命）

华语

  • 王家卫 — 花样年华 / 阿飞正传 / 重庆森林（你TODO片单里已有）
  • 杨德昌 — 一一 / 牯岭街少年杀人事件（华语电影巅峰之一，必看）
  • 侯孝贤 — 悲情城市 / 海上花 / 童年往事（长镜头静观）
  • 贾樟柯 — 站台 / 三峡好人 / 山河故人（当代中国真实影像）
  • 蔡明亮 — 你那边几点 / 不散（极简、留白、孤独）
  • 毕赣 — 路边野餐 / 地球最后的夜晚（梦境与诗意）
  • 姜文 — 阳光灿烂的日子 / 让子弹飞 / 鬼子来了

拉片 · 影像分析资源

看完一部片再看一期拉片，吸收效率翻倍。先看，再听别人讲——避免被剧透或被引导。

中文

  • 戴锦华 — 北大教授，国内最深的电影课。B站搜”戴锦华”，付费的有看理想《52倍人生》《大师》系列
  • 贾樟柯电影课 — 看理想付费课，从导演视角讲电影
  • 木鱼水心 — B站，普及型，量大覆盖广，适合入门
  • 3号厅检票员工 / 暗黑系电影 — B站，作者论分析
  • 大象点映 / 反派影评 — 偏文艺片+独立电影

英文（YouTube）

  • Every Frame a Painting — 已停更但都是神作，必刷
  • Nerdwriter1 — 单场景/单镜头拉片大师
  • Lessons from the Screenplay — 剧本与结构分析
  • The Cinema Cartography — 长篇深度，有点学术味
  • Kogonada — 影像散文（专门做小津、库布里克的对比剪辑）
  • Like Stories of Old — 哲学+电影
  • Lindsay Ellis — 文化批评视角

工具

  • 豆瓣电影 — 选片+短评+长影评
  • Letterboxd — 国外影迷社区，按导演/主题做榜单很好用
  • The Criterion Collection — 标准收藏，艺术片殿堂的官方背书
