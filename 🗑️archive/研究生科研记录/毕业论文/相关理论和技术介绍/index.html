    可验证鲁棒性概述¶

    可验证鲁棒性：概念与理论基础¶

    1. 可验证鲁棒性的基本概念¶

    可验证鲁棒性（Certified Robustness）是深度神经网络（DNN）安全性研究中的一个核心概念，旨在为模型的鲁棒性提供数学上的形式化保证。在对抗攻击的背景下，深度神经网络极易受到输入扰动的影响，即使是人类难以察觉的微小变化，也可能导致模型的错误分类。因此，如何确保模型在一定范围内的输入扰动下仍然能够保持预测稳定性，成为机器学习安全性研究的重要课题之一。不同于传统的经验性防御方法（Empirical Defenses），如对抗训练（Adversarial Training）等，可验证鲁棒性方法不依赖于特定的攻击方式，而是通过理论分析或数学优化，为给定的输入提供可证明的鲁棒性保证[1]。

    2. 形式化定义与数学建模¶

    可验证鲁棒性的核心思想是构建一个认证半径（Certified Radius），保证在该半径内的所有扰动不会改变模型的分类结果。给定一个分类模型 fθ:Rn→RCf_\theta: \mathbb{R}^n \to \mathbb{R}^C 和输入数据点 x0x_0，如果存在一个扰动范围 Bp(x0,ϵ)={x∣∥x−x0∥p≤ϵ}B_p(x_0, \epsilon) = { x \mid | x - x_0 |_p \leq \epsilon }，使得对于所有 xx 在该范围内：

    arg⁡max⁡ifθ(x)i=arg⁡max⁡ifθ(x0)i\arg\max_{i} f_{\theta}(x)i = \arg\max{i} f_{\theta}(x_0)_i

    则称模型在 x0x_0 处对 pp-范数约束下的 ϵ\epsilon 范围具有可验证鲁棒性[2]。这意味着，攻击者即使在 ϵ\epsilon 范围内进行最优攻击，也无法改变模型的分类结果，从而提供了理论上的安全保证。

    在计算可验证鲁棒性的过程中，不同的数学方法被用于推导认证半径。早期的方法主要依赖于混合整数规划（Mixed-Integer Linear Programming, MILP） 或 半定规划（Semi-Definite Programming, SDP） 来直接求解分类边界[3]。然而，这些方法计算开销较大，难以扩展到大规模深度神经网络，因此在实际应用中受限。

    3. 计算可验证鲁棒性的方法¶

    计算可验证鲁棒性通常被转换为最小分类边界问题（Minimum Classification Margin）：

    M(y0,y′)=min⁡x∈Bp(x0,ϵ)fθ(x)y0−fθ(x)y′M(y_0, y') = \min_{x \in B_p(x_0, \epsilon)} f_{\theta}(x){y_0} - f{\theta}(x)_{y'}

    其中 y0y_0 是 x0x_0 的正确类别，而 y′≠y0y' \neq y_0 是其他类别。如果对于所有 y′≠y0y' \neq y_0，都有 M(y0,y′)>0M(y_0, y') > 0，则说明在该扰动范围内，模型的预测始终保持不变，从而可以严格证明该点的可验证鲁棒性[4]。

    在计算过程中，不同的优化方法用于估计最大认证半径。除了 MILP 和 SDP，研究者们还探索了凸优化（Convex Optimization） 和 松弛方法（Relaxation Methods），以降低计算复杂度。例如，一种常见的方法是线性松弛（Linear Relaxation），用线性约束来逼近非线性神经网络的决策边界，从而使得可验证鲁棒性的计算可以转化为一个可解的优化问题[5]。尽管这些方法提升了计算效率，但在较大规模深度神经网络上仍然受到计算复杂度的限制。

    4. 认证半径的紧致性问题¶

    可验证鲁棒性方法的一个核心挑战是如何确保计算出的认证半径尽可能紧（tight bound）。如果认证半径过小，那么其实际意义不大，攻击者仍然可以通过更小的扰动成功欺骗模型；而如果计算出的认证半径过大，可能会导致理论上的过度乐观估计，掩盖模型的真实脆弱性。因此，近年来的研究着眼于开发更紧的鲁棒性界限，即通过更精确的数学推导和优化方法，使得计算出的认证半径更接近真实可抵御的最大扰动范围。例如，基于Lipschitz 约束（Lipschitz Constraint） 的方法利用神经网络的 Lipschitz 常数来推导模型的鲁棒性界限，而基于分布鲁棒性分析（Distributional Robustness Analysis） 的方法则通过统计分析构造更合理的认证范围[6]。

    5. 不同范数下的认证能力¶

    除了计算认证半径的优化问题，可验证鲁棒性的研究还涉及不同范数下的认证能力。目前，绝大多数方法主要关注ℓ2\ell_2 范数，即欧几里得距离的扰动。然而，在实际应用中，攻击者可能采用其他形式的扰动，如 ℓ1\ell_1 范数（稀疏攻击）或 ℓ∞\ell_\infty 范数（最大变化攻击）[7]。在这些不同范数下，计算可验证鲁棒性的难度各不相同。例如，在 ℓ2\ell_2 约束下，随机平滑方法能够提供较好的鲁棒性界限，而在 ℓ∞\ell_\infty 约束下，优化方法通常比随机平滑更有效。因此，不同攻击场景下可验证鲁棒性的适用性是当前研究的一个重要方向。

    6. 未来挑战与研究方向¶

    当前可验证鲁棒性的研究正在从理论分析逐步向大规模深度神经网络的应用推进。例如，在自动驾驶系统中，可验证鲁棒性方法被用于检测是否存在扰动可能导致车辆感知系统的误判。在医学影像分析领域，该方法被用于确保诊断模型不会受到数据微小变化的影响，从而提升医疗诊断的可靠性。此外，可验证鲁棒性方法也在生物识别、金融风控和网络安全等领域得到广泛关注[8]。尽管这些研究在特定场景下已经取得了一定进展，但如何在不影响模型标准精度的前提下提高可认证鲁棒性、如何降低计算成本使得鲁棒性认证方法适用于大规模模型、以及如何扩展到非欧几里得空间（如图神经网络和自然语言处理模型），仍然是未来研究的重要方向。

    随机平滑¶

    随机平滑：原理与现有方法¶

    1. 随机平滑的基本原理¶

    随机平滑（Randomized Smoothing）是一种可扩展的可验证鲁棒性方法，它通过对输入数据施加随机噪声，使得模型的决策边界变得更加平滑，从而提供可认证的鲁棒性保证[1]。在深度神经网络中，决策边界通常高度非线性，并且对输入的微小扰动极为敏感，使得攻击者能够轻易构造对抗样本。然而，如果对输入数据进行高斯噪声扰动，使得模型的预测基于多个加噪样本的统计特性而非单一点的精确值，那么攻击者很难找到有效的对抗样本，从而提高模型的鲁棒性认证能力。

    随机平滑的基本思想是通过构造一个平滑分类器（Smoothed Classifier），其决策是基于原始分类器在多个加噪样本上的多数投票结果。具体来说，给定一个基分类器 fθ(x)f_\theta(x)，随机平滑定义了一个新的分类器：

    g(x)=arg⁡max⁡cPη∼N(0,σ2I)[fθ(x+η)=c]g(x) = \arg\max_{c} \mathbb{P}{\eta \sim \mathcal{N}(0, \sigma^2 I)} [f{\theta}(x + \eta) = c]

    其中，输入数据 xx 通过施加零均值、高斯分布方差为 σ2\sigma^2 的噪声 η∼N(0,σ2I)\eta \sim \mathcal{N}(0, \sigma^2 I) 进行扰动，分类结果由投票最多的类别 决定。

    在这一框架下，研究者们基于 Neyman-Pearson 理论推导出了可验证鲁棒性界限[2]。设 pAp_A 和 pBp_B 分别表示加噪后预测为正确类别 y0y_0 和错误类别 y′y' 的概率，则模型可认证的鲁棒性半径可以通过标准正态分布的逆累积分布函数（inverse CDF）计算：

    R=σΦ−1(pA−pB)R = \sigma \Phi^{-1}(p_A - p_B)

    其中，Φ−1\Phi^{-1} 是标准正态分布的逆累积分布函数。该公式表明，如果正确类别的投票概率 pAp_A 明显高于所有其他类别的概率 pBp_B，则可以严格证明在一定范围内的输入扰动不会改变分类结果。

    2. 随机平滑的优势与局限性¶

    与传统的优化方法（如 MILP、SDP）不同，随机平滑方法的最大优势在于其可扩展性。由于该方法仅依赖于对原始分类器的噪声扰动采样，而不涉及复杂的数学优化，因此它能够轻松适用于大规模神经网络（如 ResNet、ViT 等）[3]。相比之下，基于优化的方法虽然能提供更严格的鲁棒性界限，但其计算成本通常难以扩展到大规模任务。此外，随机平滑在 ℓ2\ell_2 约束下的认证能力较强，被证明是当前ℓ2\ell_2 域中最优的可验证鲁棒性方法[2]。

    然而，随机平滑方法也存在一些固有的局限性。首先，它主要适用于ℓ2\ell_2 范数下的扰动，对于 ℓ∞\ell_\infty 或 ℓ1\ell_1 约束的攻击，其认证能力较弱[4]。其次，该方法依赖于 Monte Carlo 采样来估计分类器的投票分布，因此在计算鲁棒性界限时存在一定的随机误差。此外，由于该方法依赖于噪声的加入，它通常会导致标准分类精度下降，需要权衡模型在干净样本上的性能和鲁棒性之间的关系[5]。

    3. 现有随机平滑方法¶

    基于随机平滑的研究近年来得到了广泛关注，并衍生出了多个改进方法，以提升其认证能力和计算效率。其中，主要的方向包括：

    （1）平滑分类器的优化
    为了提升随机平滑的认证半径，研究者们提出了一些改进策略。例如，Salman 等人提出了对抗性训练的平滑分类器（Adversarially-Trained Smoothed Classifier），通过在训练过程中加入高斯噪声扰动，使得模型在平滑后的输入分布上具备更强的泛化能力[6]。这一方法有效提高了认证半径，并减少了由于噪声引入的分类精度下降。

    （2）适用于不同范数的随机平滑
    尽管标准随机平滑方法在 ℓ2\ell_2 约束下表现良好，但在 ℓ∞\ell_\infty 约束下，其认证半径相对较小。Levine 和 Feizi 提出了一种基于Wasserstein 平滑（Wasserstein Smoothing） 的方法，该方法通过对噪声分布进行调整，使其能够适用于更广泛的范数约束[7]。这一方法在某些数据集上提升了认证半径，但仍然面临计算复杂度较高的问题。

    （3）计算效率优化
    随机平滑方法的计算成本主要来自于大量采样 的需求，即每次预测都需要对输入添加多个随机噪声样本，并统计分类结果。为了提高计算效率，研究者们提出了分层平滑（Hierarchical Smoothing） 方法[8]，该方法通过在不同尺度上进行噪声采样，并采用分层投票机制，从而减少了采样的数量，提高了计算速度。此外，一些研究还尝试结合重要性采样（Importance Sampling），以减少 Monte Carlo 估计的方差，使得认证结果更加稳定。

    去噪平滑¶

    去噪平滑：原理与现有方法¶

    1. 去噪平滑的基本原理¶

    去噪平滑（Denoised Smoothing）是一种对标准随机平滑（Randomized Smoothing）的改进方法，旨在缓解噪声引入导致的分类精度下降以及分布偏移（distribution shift） 问题[1]。在传统随机平滑框架中，模型通过对输入数据施加高斯噪声进行平滑，使得其决策边界更加稳健。然而，高斯噪声的加入可能会导致输入数据分布发生变化，从而影响分类器的预测性能。此外，由于随机平滑方法依赖于投票机制，分类器可能无法很好地适应带噪输入，因此会出现一定的误分类风险[2]。

    去噪平滑的核心思想是：在施加随机噪声之后，先通过一个去噪模块（Denoiser）恢复输入数据的原始结构，再进行分类。具体来说，给定一个基分类器 fθ(x)f_\theta(x)，去噪平滑方法通过引入一个去噪函数 D(x)D(x)，构造新的平滑分类器：

    gD(x)=arg⁡max⁡cPη∼N(0,σ2I)[fθ(D(x+η))=c]g_D(x) = \arg\max_{c} \mathbb{P}{\eta \sim \mathcal{N}(0, \sigma^2 I)} [f{\theta}(D(x + \eta)) = c]

    其中：

    • xx 是输入数据，η\eta 是服从高斯分布的噪声 N(0,σ2I)\mathcal{N}(0, \sigma^2 I)。
    • D(x)D(x) 是一个去噪模型，负责将带噪数据 x+ηx + \eta 恢复到接近原始分布的形式。
    • 平滑分类器 gD(x)g_D(x) 的最终预测是基于多数投票机制计算得出的类别。

    这一方法的主要优势在于：

    1. 减少分布偏移：相比于传统的随机平滑方法，去噪平滑通过去噪模块补偿了输入噪声的影响，从而减少了高斯噪声带来的分布偏移问题[3]。
    2. 提高认证半径：实验表明，在相同噪声水平下，去噪平滑能够比标准随机平滑方法提供更大的可认证鲁棒性半径[4]。
    3. 适用于更广泛的噪声模型：去噪平滑不仅适用于高斯噪声，还可以扩展到更复杂的噪声模型，如泊松噪声或扩散噪声[5]。

    2. 去噪平滑的优势与局限性¶

    去噪平滑方法的最大优势在于在保持可认证鲁棒性的同时，提高了分类精度。在传统随机平滑方法中，由于高斯噪声的加入，基分类器的标准预测性能通常会下降，而去噪平滑能够减少这一影响，使得模型在干净数据上的表现更加稳定。此外，由于去噪模块能够恢复数据的局部结构，它能够在一定程度上减少误分类的发生，提高认证精度[6]。

    然而，去噪平滑方法也存在一些挑战：

    1. 去噪器的质量直接影响最终的认证结果。如果去噪器 D(x)D(x) 不能很好地恢复原始数据分布，那么分类器的性能可能会受到额外的影响，甚至可能导致认证半径的下降[7]。
    2. 计算开销较大。相比于标准随机平滑，去噪平滑需要额外训练或使用一个去噪模块，这会增加计算成本，特别是在使用深度生成模型（如扩散模型）时[8]。
    3. 去噪器自身的鲁棒性问题。如果去噪器本身不具备鲁棒性，那么在面对对抗性扰动时，它可能会失效，从而削弱整个去噪平滑框架的防御能力[9]。

    3. 现有去噪平滑方法¶

    近年来，研究者们提出了多种去噪平滑方法，主要的研究方向包括使用不同类型的去噪器、结合生成式模型进行去噪，以及优化计算效率。

    （1）基于传统去噪器的去噪平滑
    最早的去噪平滑方法通常采用基于卷积神经网络（CNN）的去噪器，即使用预训练的去噪神经网络来恢复被高斯噪声扰动的输入。例如，Salman 等人提出了一种使用 DnCNN 作为去噪器的去噪平滑方法，该方法在 CIFAR-10 和 ImageNet 数据集上提高了认证精度[10]。然而，由于 CNN 去噪器的能力有限，该方法在较大噪声水平下的去噪效果不佳。

    （2）扩散去噪平滑（Diffusion Denoised Smoothing, DDS）
    最近的研究表明，扩散模型（Diffusion Models） 具有更强的去噪能力，能够比传统 CNN 去噪器更好地恢复输入数据的原始分布[11]。扩散去噪平滑（DDS）方法通过使用扩散模型的逆过程（Reverse Process）来进行去噪，其计算流程如下：

    1. 选择合适的扩散时间步 t∗t^，使得扩散噪声方差匹配随机平滑的高斯噪声水平： σ2=1−αt∗αt∗\sigma^2 = \frac{1 - \alpha_{t^}}{\alpha_{t^*}} 其中 αt\alpha_t 是扩散过程中的时间参数[12]。
    2. 计算被噪声扰动的输入： xt∗=αt∗(x+η),η∼N(0,σ2I)x_{t^} = \sqrt{\alpha_{t^}}(x + \eta), \quad \eta \sim \mathcal{N}(0, \sigma^2 I)
    3. 使用扩散模型的逆过程去噪： x^=denoise(xt∗;t∗)\hat{x} = \text{denoise}(x_{t^}; t^)
    4. 将去噪后的样本输入分类器进行最终预测： y=fθ(x^)y = f_{\theta}(\hat{x})

    （3）DensePure 方法（多次去噪 + 多数投票机制）
    DensePure 方法通过多次运行扩散去噪过程，并使用多数投票机制来提高鲁棒性认证的稳定性[7]。该方法的主要步骤包括：

    1. 对每个输入 xx 进行 NN 次 去噪，每次使用不同的随机种子 sis_i，得到 NN 个去噪样本： x^i=denoise(x+ηi;si),i=1,2,...,N\hat{x}_i = \text{denoise}(x + \eta_i; s_i), \quad i = 1, 2, ..., N
    2. 计算所有去噪样本的分类结果： yi=fθ(x^i)y_i = f_{\theta}(\hat{x}_i)
    3. 采用多数投票机制作为最终分类： g(x)=arg⁡max⁡c∑i=1N1[yi=c]g(x) = \arg\max_{c} \sum_{i=1}^{N} \mathbb{1}[y_i = c]

    相比于单次去噪的方法，DensePure 通过多次去噪和投票机制能够减少单次去噪的误差，并提升整体认证稳定性。该方法的实验结果表明，在 ImageNet 数据集上，DensePure 在大范围扰动下能够取得比标准扩散去噪平滑更高的认证精度[8]。

    （4）DiffSmooth 方法（局部平滑 + 扩散去噪）
    DiffSmooth 是一种进一步优化的去噪平滑方法，旨在降低计算开销的同时保持较高的认证精度[9]。该方法在去噪平滑的基础上引入了局部平滑（local smoothing） 机制，使得模型在去噪后的样本附近添加额外的小幅度高斯噪声，以增强模型在认证边界附近的稳定性。其主要流程如下：

    1. 先使用扩散模型进行去噪，得到去噪后的样本： x^=denoise(x+η)\hat{x} = \text{denoise}(x + \eta) 其中 η∼N(0,σ2I)\eta \sim \mathcal{N}(0, \sigma^2 I)。
    2. 在去噪后的样本 x^\hat{x} 附近添加额外的小幅度高斯噪声 ξ∼N(0,σ′2I)\xi \sim \mathcal{N}(0, \sigma'^2 I)，生成局部扰动样本： x′=x^+ξx' = \hat{x} + \xi
    3. 对多个局部扰动样本进行分类，并采用多数投票机制获得最终分类结果： g(x)=arg⁡max⁡cPξ∼N(0,σ′2I)[fθ(x^+ξ)=c]g(x) = \arg\max_{c} \mathbb{P}{\xi \sim \mathcal{N}(0, \sigma'^2 I)} [f{\theta}(\hat{x} + \xi) = c]

    DiffSmooth 的核心思想是，尽管扩散模型能够很好地去噪，但其去噪结果仍然存在一定的不确定性。因此，在去噪后再进行局部扰动，可以进一步提高认证稳定性，并减少由于去噪误差导致的分类波动[10]。实验表明，DiffSmooth 在 CIFAR-10 和 ImageNet 数据集上均能取得较高的可认证精度，同时降低了去噪计算的成本，使得去噪平滑方法更加可行。

    4. 计算效率优化¶

    去噪平滑方法的计算开销主要来源于两个方面：去噪器的计算成本 和 投票机制的采样成本。特别是在使用扩散模型作为去噪器时，计算复杂度显著上升。为了解决这一问题，研究者们提出了一些优化策略，包括：

    • 单步去噪（One-Step Denoising）：使用变分自编码器（VAE）或 GAN 作为去噪器，使得去噪过程不再依赖于多步迭代计算，从而降低计算成本[11]。
    • 自适应去噪（Adaptive Denoising）：根据输入样本的置信度动态调整去噪强度，对低置信度样本使用更强的去噪模型，而对高置信度样本使用较轻量的去噪策略，以降低计算负担[12]。
    • 重要性采样（Importance Sampling）：减少 Monte Carlo 采样的方差，提高认证结果的稳定性，使得模型能够用更少的采样次数获得相似的认证效果[13]。

    这些方法在一定程度上缓解了去噪平滑的计算成本，使其更加适用于大规模神经网络，并提升了其实际应用的可行性。

    去噪平滑：原理与现有方法¶

    1. 去噪平滑的基本原理¶

    去噪平滑（Denoised Smoothing）是一种对标准随机平滑（Randomized Smoothing）的改进方法，旨在缓解噪声引入导致的分类精度下降以及分布偏移（distribution shift） 问题[1]。在传统随机平滑框架中，模型通过对输入数据施加高斯噪声进行平滑，使得其决策边界更加稳健。然而，高斯噪声的加入可能会导致输入数据分布发生变化，从而影响分类器的预测性能。此外，由于随机平滑方法依赖于投票机制，分类器可能无法很好地适应带噪输入，因此会出现一定的误分类风险[2]。

    去噪平滑的核心思想是：在施加随机噪声之后，先通过一个去噪模块（Denoiser）恢复输入数据的原始结构，再进行分类。具体来说，给定一个基分类器 fθ(x)f_\theta(x)，去噪平滑方法通过引入一个去噪函数 D(x)D(x)，构造新的平滑分类器：

    gD(x)=arg⁡max⁡cPη∼N(0,σ2I)[fθ(D(x+η))=c]g_D(x) = \arg\max_{c} \mathbb{P}{\eta \sim \mathcal{N}(0, \sigma^2 I)} [f{\theta}(D(x + \eta)) = c]

    其中：

    • xx 是输入数据，η\eta 是服从高斯分布的噪声 N(0,σ2I)\mathcal{N}(0, \sigma^2 I)。
    • D(x)D(x) 是一个去噪模型，负责将带噪数据 x+ηx + \eta 恢复到接近原始分布的形式。
    • 平滑分类器 gD(x)g_D(x) 的最终预测是基于多数投票机制计算得出的类别。

    这一方法的主要优势在于：

    1. 减少分布偏移：相比于传统的随机平滑方法，去噪平滑通过去噪模块补偿了输入噪声的影响，从而减少了高斯噪声带来的分布偏移问题[3]。
    2. 提高认证半径：实验表明，在相同噪声水平下，去噪平滑能够比标准随机平滑方法提供更大的可认证鲁棒性半径[4]。
    3. 适用于更广泛的噪声模型：去噪平滑不仅适用于高斯噪声，还可以扩展到更复杂的噪声模型，如泊松噪声或扩散噪声[5]。

    2. 去噪平滑的优势与局限性¶

    去噪平滑方法的最大优势在于在保持可认证鲁棒性的同时，提高了分类精度。在传统随机平滑方法中，由于高斯噪声的加入，基分类器的标准预测性能通常会下降，而去噪平滑能够减少这一影响，使得模型在干净数据上的表现更加稳定。此外，由于去噪模块能够恢复数据的局部结构，它能够在一定程度上减少误分类的发生，提高认证精度[6]。

    然而，去噪平滑方法也存在一些挑战：

    1. 去噪器的质量直接影响最终的认证结果。如果去噪器 D(x)D(x) 不能很好地恢复原始数据分布，那么分类器的性能可能会受到额外的影响，甚至可能导致认证半径的下降[7]。
    2. 计算开销较大。相比于标准随机平滑，去噪平滑需要额外训练或使用一个去噪模块，这会增加计算成本，特别是在使用深度生成模型（如扩散模型）时[8]。
    3. 去噪器自身的鲁棒性问题。如果去噪器本身不具备鲁棒性，那么在面对对抗性扰动时，它可能会失效，从而削弱整个去噪平滑框架的防御能力[9]。

    3. 扩散去噪平滑方法¶

    近年来，扩散模型（Diffusion Models）因其卓越的去噪能力，逐渐成为去噪平滑方法的核心研究方向[10]。相比于传统基于卷积神经网络（CNN）的去噪器，扩散模型能够通过逆扩散过程（Reverse Process） 逐步恢复输入数据的原始分布，使其具备更强的泛化能力，并减少去噪过程中可能引入的分布偏移问题。在去噪平滑框架下，扩散模型的去噪过程主要包含以下步骤：

    1. 选择合适的扩散时间步 t∗t^，使得扩散噪声方差匹配随机平滑的高斯噪声水平： σ2=1−αt∗αt∗\sigma^2 = \frac{1 - \alpha_{t^}}{\alpha_{t^*}} 其中 αt\alpha_t 是扩散过程中的时间参数[11]。
    2. 计算被噪声扰动的输入： xt∗=αt∗(x+η),η∼N(0,σ2I)x_{t^} = \sqrt{\alpha_{t^}}(x + \eta), \quad \eta \sim \mathcal{N}(0, \sigma^2 I)
    3. 使用扩散模型的逆过程去噪： x^=denoise(xt∗;t∗)\hat{x} = \text{denoise}(x_{t^}; t^)
    4. 将去噪后的样本输入分类器进行最终预测： y=fθ(x^)y = f_{\theta}(\hat{x})

    在此基础上，研究者们提出了多个扩展方法，包括：

    • DensePure 方法：通过多次运行扩散去噪过程，并使用多数投票机制，来减少单次去噪可能带来的误差，提高整体认证的稳定性[12]。该方法在 ImageNet 数据集上取得了比标准扩散去噪平滑更高的认证精度。
    • DiffSmooth 方法：在去噪后进一步添加局部高斯扰动（local smoothing），增强模型在认证边界附近的稳定性。实验表明，该方法在 CIFAR-10 和 ImageNet 数据集上均能取得较高的认证精度，同时降低了去噪计算的成本[13]。

    这些方法共同推动了去噪平滑的发展，使其成为目前最具竞争力的可验证鲁棒性框架之一。

    对抗攻击与对抗净化¶

    对抗攻击与对抗净化：理论与技术¶

    1. 对抗攻击与对抗样本¶

    对抗攻击（Adversarial Attacks）是深度学习模型面临的核心安全挑战，攻击者通过构造精心设计的扰动，使模型在推理时产生错误分类。这类攻击主要发生在测试阶段，即模型已经训练完成，攻击者希望通过构造特殊输入，使其被误分类，而不需要修改训练数据。攻击的核心机制是利用深度学习模型的非线性决策边界，在输入数据上施加微小但精心计算的扰动，使得模型在高维空间中的分类决策发生偏移。攻击者通常可以采取白盒（White-box） 和 黑盒（Black-box） 方式进行攻击，其中白盒攻击假设攻击者可以访问模型的梯度信息，而黑盒攻击仅依赖模型的输入输出行为来推测最优攻击策略。

    对抗样本（Adversarial Examples）是攻击者通过在原始输入 xx 上添加精心设计的扰动 δ\delta 生成的，使得深度神经网络 ff 误分类，即：

    f(x)≠f(x+δ)f(x) \neq f(x + \delta)

    其中 δ\delta 是一个对人类而言难以察觉的微小扰动。研究表明，许多现代神经网络模型对这种微小扰动极其敏感，使得它们即使在训练时表现良好，在测试阶段仍然容易受到攻击。典型的对抗攻击方法包括 FGSM（Fast Gradient Sign Method）、PGD（Projected Gradient Descent）、CW（Carlini & Wagner）攻击等。

    FGSM 是最早提出的白盒攻击方法之一，其核心思想是利用模型的梯度信息，通过一阶优化方法生成扰动：

    $$ x′=x+ϵ⋅sign(∇xJ(x,y))x' = x + \epsilon \cdot \text{sign}(\nabla_x J(x, y)) $$

    其中 ∇xJ(x,y)\nabla_x J(x, y) 是损失函数对输入的梯度，ϵ\epsilon 控制扰动强度。PGD 攻击是 FGSM 的迭代版本，每次迭代都计算梯度并施加微小扰动，最终得到更具攻击性的对抗样本。CW 攻击则是基于优化方法，最小化输入扰动的同时最大化误分类置信度，使得生成的对抗样本更加隐蔽。

    此外，近年来研究者提出了一些更先进的攻击方法，如 AutoAttack、DeepFool、HopSkipJump，以及物理世界中的对抗攻击。AutoAttack 结合了多种攻击方法，能够自适应地选择最优的攻击策略，提高攻击成功率[1]。DeepFool 采用优化方法找到最小的扰动量，使输入跨越决策边界，而 HopSkipJump 作为一种黑盒攻击方法，则利用零阶优化策略生成对抗样本[2]。物理世界中的攻击主要关注如何在现实环境中制造对抗样本，例如改变物体的纹理或形状，使其在计算机视觉系统中被错误识别[3]。

    对抗样本的成功攻击依赖于多个关键因素，如 扰动范数约束、模型结构的敏感性、数据分布的局部特性 以及 对抗样本的可迁移性。不同攻击方法通常针对这些因素进行优化，以提高攻击的成功率。例如，研究表明，在训练数据较稀疏的区域，对抗样本更容易找到高置信度的误分类区域；而基于梯度的攻击方法在卷积神经网络（CNN）上的效果通常优于在变换不变性的模型（如 Vision Transformer）上的效果[4]。

    2. 对抗净化与扩散模型的应用¶

    为了抵御对抗样本攻击，研究者提出了多种防御策略，其中对抗净化（Adversarial Purification） 是近年来备受关注的方法之一。对抗净化的目标是在模型进行分类之前，通过去噪、特征变换或数据修正等方式去除对抗扰动，从而恢复干净的输入样本。早期的方法包括去噪自编码器（Denoising Autoencoder, DAE），该方法利用自编码器学习无攻击版本的输入，并在推理阶段去除对抗性扰动[5]。此外，总变分最小化（Total Variation Minimization, TVM）通过优化输入图像的总变分，使其在高频信号上保持平滑，以去除对抗噪声[6]。基于生成模型的净化，如 GAN（生成对抗网络）和流模型（Flow-based Models），则利用生成式网络从受污染的样本中恢复出可能的无攻击版本[7]。然而，这些传统方法在面对复杂的对抗攻击时表现不稳定，导致研究者开始探索基于扩散模型（Diffusion Models）的对抗净化。

    扩散模型（Diffusion Models）最初用于图像生成任务，它通过前向扩散过程将输入数据逐步转换为高斯噪声，并在逆扩散过程中重建原始数据[8]。由于扩散模型具备天然的去噪能力，它能够有效去除对抗扰动，并在数据净化过程中保留语义信息，使其成为对抗净化任务中的强大工具。目前，主流的扩散净化方法包括 DiffPure、Score-based Diffusion Purification 和 Guided Diffusion Purification[9]。DiffPure 通过扩散模型的逆扩散过程去除对抗扰动，并恢复干净样本。Score-based Diffusion Purification 进一步优化了去噪过程，它利用扩散模型的噪声估计能力，动态选择扩散时间步 t∗t^*，确保恢复后的样本在特征空间中尽可能接近原始干净样本，同时不会因去噪过度而丢失关键信息[10]。Guided Diffusion Purification 方法结合了分类器引导策略，在扩散去噪过程中使用分类器的梯度信息，使得净化后的样本在分类边界附近保持稳定，而不会因去噪误差导致模型误分类[11]。

    扩散模型优化及其局限性¶

    尽管扩散模型已成为最具潜力的对抗净化方法之一，但由于涉及多个采样步骤，其计算复杂度较高，限制了其实际应用。为此，研究者提出了多种优化策略，如自适应扩散时间步（Adaptive Time Step Selection）、分类器引导净化（Classifier-Guided Diffusion Purification） 和 高效采样策略（Efficient Sampling Strategies），以提高去噪效率并降低计算成本。

    自适应扩散时间步方法通过噪声估计器动态调整去噪步数，减少计算冗余，实验表明此方法可在保证净化效果的同时降低 40% 以上的计算成本[12]。分类器引导净化利用模型梯度信息优化去噪方向，确保净化后的样本仍处于正确的类别区域，从而减少分类错误[13]。此外，高效采样策略（如 DDIM 和 EDM）通过隐式采样方法加速去噪，使扩散模型在不到 50 个采样步骤内完成净化，同时保持较高的分类精度[14][15]，显著提升了扩散净化在计算受限场景（如移动设备）中的可行性。

    然而，扩散净化的有效性依赖于攻击方式，不同类型的对抗扰动对去噪过程的影响各异。研究表明，尽管扩散模型对梯度攻击（如 PGD、CW）有较强防御能力，但在面对黑盒查询攻击（如 HopSkipJump）时，其净化效果可能下降[16]。此外，由于扩散模型本质上属于生成模型，去噪过程中可能会丢失部分细节信息，这对医学影像分析等高精度任务可能产生影响。

    为进一步提升防御能力，研究者们正探索多模态扩散净化（Multimodal Diffusion Purification） 和自适应防御策略（Adaptive Defense Strategies）。多模态净化旨在扩展扩散模型至文本、语音等模态，提高防御范围[17]。自适应防御策略则通过动态调整去噪强度，根据输入样本的扰动水平自动优化净化过程，以应对不同类型的对抗攻击[18]。随着计算效率的提升和新型防御策略的提出，扩散净化技术在深度学习安全领域的应用前景将进一步拓展。

    掩码自编码器¶

    掩码自编码器（Masked Autoencoders, MAE）及其技术原理¶

    1. 引言¶

    随着深度学习的发展，自监督学习在计算机视觉任务中展现出重要作用。相比于传统的监督学习方法，自监督学习能够利用大量无标签数据进行预训练，从而提高模型的特征学习能力。近年来，掩码语言模型（Masked Language Modeling, MLM）在自然语言处理领域的成功，如 BERT 预训练策略，启发了研究者们在视觉任务中探索类似的自监督学习方法。掩码自编码器（Masked Autoencoders, MAE）便是一种借鉴此思路的自监督预训练方法。其核心思想是通过对输入图像进行高比例的随机遮挡，并训练模型恢复缺失部分，以此获取具有语义信息的视觉特征表示 [1]。

    MAE 主要包含高比例遮挡策略、非对称编码器-解码器架构和高效的视觉表征学习。相比于对比学习等传统自监督方法，MAE 直接通过图像恢复任务引导模型学习深层语义特征，而不依赖额外的数据增强或负样本对 [2]。这种设计不仅减少了计算成本，还提高了训练效率，使得 MAE 在大规模数据集上展现出优越的特征迁移能力。

    2. 掩码自编码器的核心原理¶

    MAE 的设计受到去噪自编码器（Denoising Autoencoders, DAE）的启发，即在输入数据上施加扰动（如加入噪声或删除部分内容），然后训练模型恢复原始数据。在 MAE 方法中，输入图像首先被划分为一系列非重叠的图像块（Patch），然后随机丢弃大部分 Patch，仅保留一小部分作为输入，让模型学习重建被遮挡的部分 [3]。与 NLP 任务中的 BERT 仅对 15% 的 token 进行遮挡不同，MAE 采用极高的遮挡比例（通常为 75% 甚至更高），以促使模型学习更深层次的全局视觉特征，而不仅仅是局部像素关联信息 [4]。

    MAE 采用了非对称的编码器-解码器架构，其中编码器仅对可见 Patch 进行处理，并不会引入额外的 Mask Token，这一设计区别于 BEiT 等方法 [5]。在编码器提取高层次特征后，解码器负责接收编码器的输出，并加入 Mask Token 来补全缺失信息，最终生成完整的图像。解码器通常是一个较轻量级的网络，以降低计算成本，使整个训练过程更加高效 [6]。由于编码器只需处理少量可见 Patch，MAE 相比于其他自监督学习方法计算量显著降低，这使得它可以在更大规模的数据集上进行高效训练 [7]。

    在训练过程中，MAE 采用均方误差（Mean Squared Error, MSE）作为重建损失函数，仅在被遮挡的 Patch 上计算误差 [8]。这种设计不同于 NLP 任务中的 BERT，后者采用交叉熵损失预测离散的 token，而 MAE 直接回归像素值。这种损失形式使得模型能够学习更加细粒度的视觉特征，并提升全局和局部信息的整合能力 [9]。

    3. MAE 的优势与局限性¶

    MAE 在计算效率上表现突出。由于编码器仅需处理 25% 的可见 Patch，训练计算量相较于其他自监督学习方法显著减少。研究表明，相比于 BEiT 和 MoCo 等方法，MAE 的训练时间减少了 3 倍以上，同时在下游任务（如图像分类、目标检测和语义分割）上仍能取得优越的表现 [10]。此外，高遮挡策略使得模型能够关注更广泛的全局特征，而不仅仅依赖局部信息，从而增强在不同数据集上的泛化能力 [11]。

    尽管 MAE 具有诸多优点，但仍然存在一定的局限性。由于 MAE 主要依赖像素级别的重建，而不像 BEiT 采用视觉词典（Visual Tokenization），因此其在语义建模能力上可能稍逊 [12]。此外，MAE 在小规模数据集上的适应性可能不如传统的监督学习方法，因为它更依赖于大规模预训练 [13]。在一些特定任务（如视频分析或 3D 视觉任务）中，MAE 的应用仍然受到一定限制，需要结合任务特定的改进策略 [14]。

    参数高效微调¶

    参数高效微调（Parameter-Efficient Fine-Tuning, PEFT）¶

    1. 引言¶

    随着大规模预训练模型（Pre-trained Models）在自然语言处理（NLP）和计算机视觉（CV）等领域的广泛应用，微调（Fine-Tuning）成为适应不同下游任务的核心技术。然而，传统的全量微调（Full Fine-Tuning） 需要更新所有模型参数，对于包含数十亿参数的 Transformer 模型（如 GPT-3 175B、PaLM 540B），微调的计算和存储成本极其高昂[1]。全量微调不仅要求大量计算资源，还可能导致灾难性遗忘（Catastrophic Forgetting），即模型在新任务上表现良好，但丧失了在原始任务上的能力[2]。因此，研究者们提出了参数高效微调（Parameter-Efficient Fine-Tuning, PEFT） 方法，以在仅更新少量参数的情况下，实现与全量微调接近的效果，同时显著降低计算和存储需求[3]。

    PEFT 通过只调整模型的一部分参数或优化输入策略，避免了大规模参数更新的计算开销。目前，主流的 PEFT 方法包括适配器（Adapters）、低秩适配（LoRA）、提示微调（Prompt-Tuning） 和 前缀微调（Prefix-Tuning），它们在不同任务中表现出色，并在 NLP 和计算机视觉（CV）领域得到了广泛应用[4]。

    2. 适配器（Adapters）¶

    适配器（Adapters）是一种模块化的微调方法，其核心思想是在预训练模型的 Transformer 层间插入小型可训练神经网络，而保持主干模型参数冻结[5]。适配器通常由两层前馈神经网络（MLP）组成，具有非线性变换能力，在不同任务之间共享主干网络，仅需存储适配器参数。AdapterHub 框架进一步促进了适配器的广泛应用，使得不同任务的适配器可以无缝集成到 Transformer 模型（如 BERT、RoBERTa）中[6]。

    适配器的最大优势在于存储高效。对于每个任务，仅需存储少量适配器参数，而不需要保存整个模型的权重，适配器参数的存储需求通常是原始模型的 1-5%，适用于多任务场景[7]。这使得适配器能够在资源受限的计算环境（如边缘设备或云端服务）中被广泛应用，并且能够快速切换不同任务。然而，适配器的一个显著缺点是推理时的额外计算开销，由于每层 Transformer 需要额外计算适配器模块，这可能会导致推理速度下降，尤其在高吞吐量任务（如实时语音翻译）中影响明显[8]。

    3. 低秩适配（LoRA, Low-Rank Adaptation）¶

    LoRA（Low-Rank Adaptation）是一种通过低秩矩阵分解优化 Transformer 结构的微调方法。其核心思想是，在 Transformer 层的权重更新过程中，不直接修改原始权重矩阵，而是通过引入两个小型矩阵 A∈Rr×dA \in \mathbb{R}^{r \times d} 和 B∈Rd×rB \in \mathbb{R}^{d \times r} 进行替代更新：

    ΔW=BA\Delta W = B A

    其中 r≪dr \ll d 确保了更新矩阵的维度远小于原始权重矩阵 WW 的维度，从而减少存储和计算需求[9]。

    LoRA 的一个突出优势在于不会影响推理效率，因为训练完成后，ΔW\Delta W 可以直接合并到原始模型参数 WW 中，使得推理时的计算成本与全量微调相当[10]。此外，LoRA 在超大规模 Transformer 模型（如 GPT-3 175B）上表现尤为出色，实验表明，在 LoRA 中仅需0.1% 的可训练参数即可实现与全量微调相当的性能，同时显著降低显存占用[11]。

    然而，LoRA 适用于参数更新空间具有低秩结构的任务，但并非所有任务都满足这一假设。例如，在某些多模态任务（如文本-图像联合建模）中，LoRA 可能不如适配器或全量微调稳定[12]。

    4. 提示微调（Prompt-Tuning）¶

    Prompt-Tuning 是一种基于优化输入提示（Prompts）的参数高效微调方法，其核心思想是不调整模型参数，而是优化特定任务的前缀输入[13]。这种方法通过学习可训练的软提示（Soft Prompts），使得预训练模型能够在不改变模型结构的情况下适应新任务[14]。

    Prompt-Tuning 的优势在于计算开销极低，因为它仅涉及输入级别的优化，适用于计算资源受限的环境，如低功耗 AI 设备或云端 API 服务。此外，Prompt-Tuning 在跨任务泛化能力上表现出色，尤其在低资源场景下，可以通过少量任务示例（Few-shot Learning）快速适应不同任务[15]。然而，由于 Prompt-Tuning 不涉及模型参数更新，其优化过程可能较慢，且收敛性依赖于预训练模型的原始能力。如果模型在预训练阶段没有见过目标任务的数据分布，那么 Prompt-Tuning 的效果可能受限[16]。

    5. 前缀微调（Prefix-Tuning）¶

    前缀微调（Prefix-Tuning）是 Prompt-Tuning 的增强版本，区别在于它不仅优化输入前缀，还优化 Transformer 内部的连续前缀向量，影响整个注意力机制[17]。与 Prompt-Tuning 只影响输入不同，Prefix-Tuning 在Transformer 的每一层插入可训练的前缀向量，从而让模型在不同任务上更具适应性[18]。

    Prefix-Tuning 的一个显著优势是能够调整 Transformer 内部信息流，使其适应更复杂的任务，特别是在文本生成任务（如对话系统、机器翻译）中表现突出[19]。然而，Prefix-Tuning 的优化难度较大，尤其在大规模 Transformer 模型中，可能需要更复杂的梯度优化方法来确保收敛[20]。

    其次，我们详细介绍了随机平滑方法，它通过在输入数据上施加随机噪声，使模型的决策边界变得更加平滑，从而提供可认证的鲁棒性界限。我们分析了随机平滑的数学原理，基于 Neyman-Pearson 理论推导了认证半径，并探讨了其计算可扩展性及在 ℓ2\ell_2 范数下的优势。同时，我们回顾了随机平滑的局限性，包括对 ℓ∞\ell_\infty 和 ℓ1\ell_1 扰动的适应性问题，以及采样误差和分类精度下降的影响。此外，我们总结了近年来基于随机平滑的改进方法，如对抗性训练的平滑分类器、适用于不同范数约束的平滑方法、以及计算优化策略，如分层平滑和重要性采样，以进一步提升认证精度和计算效率。

    随后，我们探讨了去噪平滑技术，这是对随机平滑的一种增强方法，旨在减少因加入噪声导致的分类精度下降和分布偏移问题。去噪平滑通过在加噪后引入去噪模块，使得分类器能够在恢复后的输入上进行预测，从而提高认证鲁棒性。我们介绍了不同类型的去噪方法，包括基于传统去噪器的 CNN 去噪方法、基于扩散模型的去噪方法、以及结合生成式模型的去噪策略，并探讨了其计算开销与适用性。此外，我们分析了去噪器质量对整体认证效果的影响，并总结了优化去噪过程的几种方法，如单步去噪、自适应去噪和高效采样策略，以降低计算复杂度并提升鲁棒性。

    在本章的后半部分，我们重点分析了对抗攻击与对抗净化技术。我们首先回顾了对抗攻击的基本概念，介绍了对抗样本的生成方式，并分类讨论了白盒攻击、黑盒攻击等不同攻击类型及其对深度学习模型的威胁。随后，我们探讨了基于梯度优化的攻击方法，如 FGSM、PGD 和 CW 攻击，以及最新的黑盒攻击方法，如 AutoAttack 和 HopSkipJump。接着，我们介绍了对抗净化方法，特别是基于扩散模型的净化技术。我们分析了扩散模型的工作原理，以及如何通过扩散去噪过程去除输入中的对抗扰动。我们还总结了目前主流的扩散净化方法，包括 DiffPure、Score-based Diffusion Purification 和 Guided Diffusion Purification，并探讨了如何通过自适应扩散时间步、分类器引导净化和高效采样策略优化计算效率。

    最后，我们介绍了掩码自编码器（MAE）及其在计算机视觉中的应用。MAE 作为一种自监督学习方法，通过高比例的掩码策略，使模型学习全局视觉特征，并在大规模数据集上展现了卓越的迁移能力。我们分析了 MAE 的编码器-解码器架构、训练损失及其与 NLP 任务中的掩码语言模型的异同。同时，我们探讨了 MAE 在计算效率和特征学习方面的优势，并分析了其在小规模数据集上的局限性及未来可能的优化方向。
